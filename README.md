# Lake of souls launcher

## Об лаунчере
Это лаунчер для игры Lake of Souls. Он может скачивать, обновлять, восстанавливать и запускать игру.

## Об игре
Ссылка на репозиторий с игрой: https://github.com/RolicsVin/lake-of-souls.

## Скачать готовые exe файлы
Если хотите сразу скачать .exe файл и протестировать - зайдите в папку bin и скачайте.
